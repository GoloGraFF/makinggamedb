> [!quote]- Мои ответы

## Цель урока

Разобраться, из чего собирается игра в Godot: ориентироваться в редакторе, собирать сцену из узлов, менять свойства в Инспекторе и вставлять одну сцену в другую.

## Теория

**Сцена и узел (аналогия с LEGO).** Узел — деталь с одной работой (Sprite2D показывает картинку, Label — текст, Camera2D снимает, Timer считает время). Сцена — модель из деталей, сохранённая в файл `.tscn`. Сцену можно вставить в другую сцену как одну деталь: «Уровень» собирает много копий «Монеты», «Врага», «Игрока».

**Окна редактора.**
- **Сцена** (слева вверху) — дерево узлов.
- **Файловая система** (слева внизу) — файлы проекта, корень `res://`.
- **Вьюпорт** (центр) — вкладки 2D / 3D / Скрипт / AssetLib.
- **Инспектор** (справа) — свойства выделенного узла; рядом вкладка **Узел/Сигналы**.
- **Вывод** (внизу) — сообщения и ошибки.

**Дерево сцены.**
- У сцены ровно один корневой узел.
- Ребёнок наследует положение, поворот, масштаб (и цвет) родителя — как колёса едут вместе с машиной.
- Цвет иконки: синие — 2D, зелёные — интерфейс (Control, Label), красные — 3D, белые — служебные.

**Инспектор.** Свойства сгруппированы по «родословной»: Sprite2D → Node2D (Transform) → CanvasItem (Visibility: Visible, Modulate) → Node. Стрелка ↺ — значение отличается от стандартного, клик возвращает его. Каждое свойство — переменная, доступная из кода:

```gdscript
extends Node2D

func _ready():
    position = Vector2(200, 150)
    rotation_degrees = 15
    modulate = Color(1, 0.5, 0.5)
```

**Экземпляр сцены.** Вставленная копия (значок «хлопушки»). Изменения оригинала `.tscn` приходят во все экземпляры, кроме свойств, *переопределённых* у самого экземпляра.

**Удалённое дерево.** Во время запуска кнопка «Удалённое» в доке Сцена показывает дерево работающей игры; свойства можно менять на лету, после остановки они не сохраняются.

Что улучшить (на зачёт не влияет):
1. Подписи средней карточки наезжают на левую — раздвинь карточки по X (например, 0 / 400 / 800).
2. У правой карточки синими стали и иконка, и текст: Modulate красит узел вместе со всеми детьми. Чтобы покрасить только сам узел, используй **Self Modulate**.

```gdscript
# Modulate — цвет узла И всех его детей
$Row/Card3.modulate = Color(0, 0, 1)
# Self Modulate — цвет только самого узла, дети не меняются
$Row/Card3.self_modulate = Color(0, 0, 1)
```

> [!tip] Главное правило урока
> Родитель передаёт детям положение, поворот, масштаб и цвет. Группируй узлы так, как они должны двигаться вместе.
