# Установка ГИТ на Android

1. Скачиваете [Termux](https://play.google.com/store/apps/details?id=com.termux) из GooglePlay
2. Открываете, проверяете установлены ли утилиты gh и git.
3. Если не установлены то устанавливаете. 
4. Далее согласно инструкции создаете токен для авторизации и заходите в свой аккаунт GitHub.
